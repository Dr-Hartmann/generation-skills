# Спецификация миниприложений для коротких видео

## Назначение

Этот комплект определяет требования к интерактивам для вертикальных коротких видео.

Итог реализации — самостоятельная HTML-страница, которую можно открыть непосредственно из файла.

## Как использовать комплект

1. Прочитай этот файл.
2. Прочитай `00_Реестр_параметров.md`. Это единственный источник числовых, цветовых, размерных и временных значений.
3. Прочитай все тематические спецификации: от `01` до `08`.
4. Создай приложение, соблюдая требования и критерии приёмки.

Файлы `01`–`08` описывают поведение и правила реализации. Они ссылаются на параметры по идентификаторам из реестра и не должны повторно задавать значения этих параметров.

## Единственный источник истины

`00_Реестр_параметров.md` — единственное место, где задаются:

1. числовые значения, диапазоны, пороги и размеры;
2. цвета, шрифты и визуальные токены;
3. контрольные размеры экранов;
4. значения временных интервалов, скорости и масштаба;
5. ограничения на количество и длину субтитров.

- Если параметр нужно изменить, измени его только в реестре. Затем проверь все связанные требования по идентификатору параметра. Не добавляй в тематические файлы копии значений.
- Каждый новый параметр сначала добавляется в реестр и получает уникальный идентификатор.
- Запрещено создавать второй параметр с тем же смыслом.
- Если два требования нуждаются в одном значении, они должны ссылаться на один идентификатор.

## Приоритет требований при конфликте

Применяй следующий порядок приоритета:

1. Безопасные зоны интерфейса коротких видео.
2. Геометрия и адаптивная компоновка.
3. Требования выбранного режима отображения, включая режим вертикальной рамки.
4. Визуальное оформление и декоративные эффекты.

Практические следствия:

- На мобильном устройстве правая зона, зарезервированная под элементы социальной платформы, остаётся пустой. Canvas, размытый фон, субтитры и контролы не должны заходить в неё.
- Режим вертикальной рамки не отменяет безопасные зоны. Он должен уместиться в доступной области.
- В режиме вертикальной рамки субтитры и контролы располагаются внутри рамки. Это специальное исключение из обычного размещения субтитров на ПК.
- Если декоративный эффект конфликтует с безопасной зоной или читаемостью, декоративный эффект отключается.

## Термины

- **Основной экран** — экран приложения без открытого окна настроек.
- **Canvas** — область визуализации: HTML Canvas или другой используемый рендерер.
- **Шаг** — логическое состояние визуализации, которому соответствует один субтитр.
- **AUTO** — режим непрерывного автоматического воспроизведения последовательности шагов.
- **STEP** — режим ручного перехода между шагами.
- **Правая безопасная зона** — область мобильного экрана, оставленная свободной для интерфейса социальной платформы.
- **Нижняя безопасная зона** — область мобильного экрана, оставленная свободной для описания, музыки и других элементов платформы.
- **Режим вертикальной рамки** — отображение визуализации в рамке с соотношением сторон из реестра параметров.

## Запрет на расхождение спецификаций

Не трактуй повторение одного требования в разных файлах как возможность выбрать удобный вариант.

При любом расхождении сначала проверь реестр параметров и правила приоритета выше.

Если в реестре параметра нет, не придумывай его значение молча: добавь параметр в реестр либо используй качественное требование без фиксации произвольного числа.

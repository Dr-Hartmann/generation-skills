# Архитектура кода и технические требования

## Разделение ответственности

Общий runtime, DOM, управление, состояние шагов, таймеры, переходы, настройки, размеры Canvas и горячие клавиши реализует app-generator.

Для конкретной темы агент создаёт только:

- scene.json — заголовок, описание, шаги и субтитры;
- scene.js — код рисования через window.AppScene.

Не создавай второй runtime и не переписывай стандартные функции генератора.

## Обязательный API сцены

В scene.js определи:

~~~js
window.AppScene = {
  draw(ctx, frame) {
    // Синхронная отрисовка текущего кадра.
  }
};
~~~

Функция draw получает контекст Canvas и объект frame. Полный состав frame приведён в app-generator/README.md.

Функция должна:

- только рисовать переданное состояние;
- не менять frame и глобальное состояние runtime;
- не управлять номером шага и субтитрами;
- не регистрировать DOM-обработчики;
- не запускать таймеры или requestAnimationFrame;
- не менять размеры и стили Canvas;
- не загружать локальные ресурсы через fetch или dynamic import.

## Необязательные методы

При необходимости объект AppScene может содержать:

- init(api) — одноразовая подготовка сцены после инициализации Canvas;
- resize(viewport) — уведомление сцены об изменении размеров;
- reset() — сброс только внутреннего состояния сцены.

Эти методы не должны создавать конкурирующие контролы, цикл анимации или модель шагов. Объект api содержит общие функции управления, перечисленные в app-generator/README.md.

## Canvas и координаты

Генератор отвечает за CSS-размеры, внутренний буфер Canvas, devicePixelRatio и ResizeObserver. Сцена получает актуальные width и height в каждом frame.

Размещай графику в координатах относительно размеров Canvas. Сохраняй пропорции и учитывай frame.fit. Не считай размеры окна или устройства самостоятельно.

## Надёжность

Код сцены должен быть детерминированным относительно переданного frame: одинаковые входные значения должны давать одинаковую отрисовку.

Проверяй локально наличие необходимых данных и корректность вычисляемых координат. Не обращайся к несуществующим полям API. Ошибки реализации сцены должны быть исправлены в scene.js, а не маскироваться заменой или дублированием общего runtime.

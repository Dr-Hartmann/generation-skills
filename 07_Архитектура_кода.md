# Архитектура кода и технические требования

## Обязательные логические функции

Организуй JavaScript вокруг следующих функций или явно эквивалентных им:

| Функция                 | Ответственность                                                                                                        |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `init()`                | Получить DOM-элементы, создать состояние, настроить canvas, подписаться на события и подготовить приложение к запуску. |
| `startAuto()`           | Запустить цикл автоматического воспроизведения.                                                                        |
| `onStep()`              | Выполнить переход на следующий логический шаг.                                                                         |
| `update(dt)`            | Обновить состояние анимации с учётом прошедшего времени.                                                               |
| `draw()`                | Отрисовать текущее состояние без изменения логики шага.                                                                |
| `updateSubtitles(step)` | Показать субтитр, соответствующий заданному шагу.                                                                      |
| `handleInput(event)`    | Обработать клавиатурный ввод.                                                                                          |
| `resize()`              | Пересчитать размеры canvas, плотность пикселей и масштаб визуализации.                                                 |
| `openSettings()`        | Открыть окно настроек и обновить его отображаемое состояние.                                                           |
| `closeSettings()`       | Закрыть окно настроек.                                                                                                 |
| `toggleVideoMode()`     | Переключить режим вертикальной рамки без сброса шага.                                                                  |

Допускается добавлять вспомогательные функции: `reset()`, `setMode()`, `setSpeed()`, `setPlaying()`, `nextStep()`, `renderControls()` и другие. Не объединяй несвязанные ответственности в одной функции.

## Структура состояния

Храни состояние в одном согласованном объекте или в нескольких явно разделённых объектах. Источник текущего шага должен быть один. Не дублируй номер шага отдельно в визуализации, субтитрах и индикаторе настроек.

Все представления интерфейса должны получать значения из общего состояния. Обновление состояния должно приводить к согласованному обновлению canvas, субтитров и контролов.

## Canvas и плотность пикселей

Разделяй CSS-размер canvas и его внутренний буфер отрисовки. CSS-размер определяет геометрию на странице; внутренний размер учитывает `devicePixelRatio`.

После изменения размеров контейнера пересчитывай внутренний буфер и масштаб контекста. Не изменяй логические координаты сцены только из-за изменения плотности пикселей.

Используй правило масштабирования `LAY-09`. Координаты визуализации должны сохранять пропорции и не обрезаться.

## События и очистка

Регистрируй обработчики событий централизованно. Не создавай новый обработчик `resize`, `keydown` или `pointer` при каждом кадре.

При необходимости повторной инициализации удаляй старые обработчики и отключай предыдущий `ResizeObserver`, чтобы не создавать дубликаты.

Для сенсорного взаимодействия используй `touch-action: manipulation` и отключай случайное выделение интерфейсных элементов через `user-select: none`. Не блокируй доступные браузерные действия для элементов, которым они необходимы.

## Надёжность

Проверяй наличие DOM-элементов до обращения к ним. Не допускай обращения к неинициализированному canvas-контексту.

Ошибки инициализации и подключения необязательных зависимостей должны обрабатываться явно. Не оставляй бесконечную анимацию загрузки при невозможности запустить визуализацию.

Код должен быть читаемым и разделённым по ответственности. Не добавляй в итоговый HTML пояснительные комментарии, если задача требует чистый файл без комментариев.

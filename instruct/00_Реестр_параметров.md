# Реестр параметров — единственный источник истины

Все значения, перечисленные в этом документе, являются нормативными. В остальных файлах используются только идентификаторы параметров.

## Формат и запуск

| ID     | Параметр                      | Единственное нормативное значение                                           | Применение                                                        |
| ------ | ----------------------------- | --------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| FMT-01 | Количество итоговых файлов    | Один HTML-файл                                                              | Весь интерактив, стили и логика находятся в одном файле.          |
| FMT-02 | Метатег viewport              | `width=device-width, initial-scale=1, viewport-fit=cover, user-scalable=no` | Используется без изменения в HTML.                                |
| FMT-03 | Подключение внешних библиотек | CDN `jsdelivr`, `unpkg` или `cdnjs`                                         | Подключать только библиотеки, которые действительно используются. |

## Правила использования реестра

- Если параметр указан в этой таблице, не задавай его значение повторно в другом файле.
- Если параметр упоминается в спецификации, используй его ID, например `LAY-02`.
- Если одному понятию соответствуют несколько чисел, каждое число должно быть явно описано как отдельная составляющая одного параметра либо получить собственный ID.
- Не выводи производные значения вручную, если их можно рассчитать из CSS-переменных и геометрии контейнера.
- Изменение параметра выполняется только в этом файле. Ссылки на его ID в других файлах остаются неизменными.

## Принятые решения по конфликтам исходной версии

- Вместо независимых нижних отступов панели и субтитров используется единая нижняя безопасная зона `LAY-05`: панель ставится над ней, субтитры — над панелью с зазором `LAY-08`. Это устраняет риск взаимного наложения.
- Правая мобильная зона `LAY-02` имеет приоритет над полноширинным декоративным фоном и режимом вертикальной рамки. В этой полосе не рисуются даже размытые декоративные слои.
- Значение `LAY-05` заменяет прежние отдельные рекомендации по нижнему отступу панели и субтитров. Не добавляй к нему старые отступы как дополнительные независимые ограничения.
- В режиме вертикальной рамки субтитры перемещаются внутрь рамки. На ПК это правило имеет приоритет над обычным размещением субтитров в боковой панели.

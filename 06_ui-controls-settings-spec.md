# Interface, Controls, and Settings Modal

This file is the English reference for the interface rules. The normative implementation is app-generator/templates/document.html, app-generator/templates/app.css, and app-generator/templates/runtime.js. For Russian-language clarification, see 06_Интерфейс_и_настройки.md.

Do not create or edit shared interface elements in the scene. The generator owns the main screen, Play/Pause and settings controls, modal dialog, AUTO/STEP selector, speed selector, portrait mode, Reset, keyboard shortcuts, accessibility attributes, and their state synchronization.

If this document conflicts with the canonical generator or its JSON specification, the generator takes precedence.

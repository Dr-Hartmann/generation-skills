# Субтитры и синхронизация с визуализацией

## Источник данных

Субтитры задаются непосредственно в app-generator input scene.json. Для каждого шага используется одно строковое поле subtitle:

~~~json
{
  "title": "Название темы",
  "description": "Краткое описание",
  "steps": [
    { "subtitle": "Первый субтитр." },
    { "subtitle": "Второй субтитр." }
  ]
}
~~~

Не создавай отдельный массив HTML-субтитров, DOM-элементы, сегменты текста или самостоятельную систему синхронизации.

## Количество и содержание

Количество шагов и субтитров должно соответствовать SUB-01. Каждый шаг содержит ровно один субтитр длиной не более SUB-02 слов.

Каждый субтитр:

- написан на русском языке;
- передаёт одну законченную мысль;
- не дублирует дословно заголовок темы;
- соответствует логическому состоянию визуализации этого шага;
- не содержит HTML-разметки или инструкций по оформлению.

Номера шагов не задаются вручную: их порядок в массиве steps является источником последовательности.

## Синхронизация

Генератор автоматически показывает subtitle текущего шага, обновляет индикатор и синхронизирует текст с завершением визуального перехода. Не обновляй субтитры самостоятельно и не храни их копию в JavaScript-состоянии сцены.

В функции AppScene.draw(ctx, frame) используй frame.step и frame.stepIndex, чтобы изображение соответствовало субтитру текущего шага.

## Оформление

Размер шрифта, подложка, размытие, анимация появления и расположение субтитров задаются app-spec.json и CSS-шаблоном генератора.

Не создавай CSS-классы, элементы DOM или Canvas-текст для замены системных субтитров. Текстовые надписи, являющиеся частью самой иллюстрации, допустимы, но не должны дублировать HTML-субтитр.

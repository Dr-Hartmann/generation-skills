# Субтитры и синхронизация с визуализацией

## Данные субтитров

Субтитры хранятся в массиве объектов. Используй структуру:

```js
{
  step: 1,
  segments: [
    { text: "Обычный фрагмент " },
    { text: "ключевого текста", emphasis: true }
  ]
}
```

Поле `step` — целочисленный номер шага, начиная с первого. `segments` — последовательность фрагментов, которая вместе образует одну фразу. Поле `emphasis` необязательно; при `true` фрагмент отображается акцентным цветом.

Для вывода акцентных фрагментов используй отдельный CSS-класс, например `.subtitle__keyword`. Не используй несуществующий HTML-атрибут `color` у `span`.

Не вставляй пользовательский текст через `innerHTML`. Создавай текстовые узлы и элементы через DOM API, чтобы содержимое субтитров интерпретировалось как текст, а не как HTML.

## Количество и содержание

Количество шагов должно соответствовать `SUB-01`. На каждый шаг приходится ровно один субтитр.

Каждый субтитр:

- написан на русском языке;
- содержит не более `SUB-02` слов;
- передаёт одну законченную мысль;
- не дублирует дословно заголовок темы;
- соответствует именно тому визуальному состоянию, которое показывается на этом шаге.

Номера `step` должны быть уникальными, последовательными и покрывать всю последовательность шагов без пропусков.

## Синхронизация

При изменении `currentStep` вызывай `updateSubtitles(step)` или эквивалентную функцию. Не меняй текст субтитров из независимого таймера.

В `AUTO` субтитр меняется синхронно с переходом визуализации на следующий шаг.

В `STEP` субтитр обновляется при ручном переходе и остаётся неизменным после завершения шага до следующей команды.

## Размещение

На мобильном устройстве в обычном режиме субтитры находятся над нижней панелью управления. Между ними выдерживается зазор `LAY-08`. Весь блок расположен внутри доступной мобильной области и не пересекает правую или нижнюю безопасную зону.

На ПК в обычном режиме субтитры находятся в правой боковой панели.

В режиме вертикальной рамки субтитры размещаются внутри рамки независимо от типа устройства. В этом режиме правило размещения внутри рамки имеет приоритет над обычным размещением в боковой панели.

## Оформление

Размер шрифта задаётся `SUB-03`. Используй полупрозрачную подложку `SUB-04` и размытие `SUB-05`.

Добавь скругление углов и достаточные внутренние отступы. Блок должен иметь стабильную минимальную высоту, чтобы смена короткого и длинного текста не сдвигала canvas и элементы управления.

При появлении субтитра используй сочетание fade-in и небольшого slide-up. Анимация не должна задерживать обновление текста или нарушать синхронизацию шага.

# Интерфейс, управление и окно настроек

## Основной экран

Основной экран содержит только следующие элементы:

- заголовок темы;
- область визуализации;
- субтитры;
- нижнюю панель управления.

В нижней панели находятся только:

- кнопка Play/Pause;
- кнопка открытия настроек с иконкой шестерёнки.

Не размещай на основном экране дополнительные кнопки, индикаторы, переключатели или декоративные карточки. Дополнительные функции находятся в окне настроек.

На мобильном устройстве панель находится над нижней безопасной зоной. На ПК она располагается в нижней части области приложения. В режиме вертикальной рамки контролы перемещаются внутрь рамки.

## Окно настроек

Окно открывается по нажатию кнопки с шестерёнкой. Оно располагается по центру, использует визуальный стиль приложения и затемняет фон.

Окно закрывается:

- кнопкой закрытия;
- нажатием на затемнённую область вне окна;
- клавишей `Esc`;
- повторным нажатием кнопки с шестерёнкой.

Нажатие внутри самого окна не должно закрывать его как клик вне окна.

При открытии используй fade-in и масштабирование от значения `ANI-04` к обычному масштабу. При закрытии используй обратную плавную анимацию.

Окно не должно выходить за пределы доступной высоты. Ограничение высоты задаётся `UI-02`; если содержимое не помещается, прокручивается внутреннее содержимое окна.

## Содержимое настроек

Размести в окне:

1. Заголовок «Настройки».
2. Индикатор текущего шага «Шаг X / Y».
3. Переключатель `AUTO` / `STEP`.
4. Кнопку «Следующий шаг ▶».
5. Выбор скорости из вариантов `ANI-03`.
6. Переключатель режима вертикальной рамки.
7. Кнопку `Reset`.
8. Краткую справку по горячим клавишам.

Кнопка «Следующий шаг ▶» визуально и функционально активна только в режиме `STEP`, если переход не выполняется и достигнут не последний шаг. В остальных случаях она отключена.

Настройка скорости должна явно показывать выбранное значение. Не добавляй другие значения скорости.

## Горячие клавиши

Горячие клавиши работают на ПК:

| Клавиша | Действие                                                         |
| ------- | ---------------------------------------------------------------- |
| `Space` | Скрыть или показать элементы управления.                         |
| `→`     | Перейти к следующему шагу; действие выполняется только в `STEP`. |
| `R`     | Выполнить Reset.                                                 |
| `S`     | Переключить `AUTO` / `STEP`.                                     |
| `V`     | Включить или выключить режим вертикальной рамки.                 |
| `Esc`   | Закрыть окно настроек, если оно открыто.                         |

При обработке клавиш не перехватывай ввод, когда пользователь взаимодействует с редактируемым полем. Для служебных клавиш, которые браузер обрабатывает по умолчанию, предотвращай стандартное действие только тогда, когда приложение действительно обрабатывает соответствующее нажатие.

Скрытие элементов управления не должно отключать горячие клавиши. Заголовок, canvas и субтитры не считаются элементами управления и не должны исчезать по `Space`.

## Доступность и обратная связь

У каждой кнопки должно быть понятное доступное имя (`aria-label` или видимый текст). Для Play/Pause имя и иконка отражают текущее действие.

Интерактивные элементы должны иметь различимые состояния: обычное, hover для устройств с hover, focus-visible, active и disabled.

Размер области нажатия каждой кнопки должен соответствовать `UI-01`. Не делай кликабельной только маленькую иконку, если вокруг неё есть место для увеличения области нажатия.

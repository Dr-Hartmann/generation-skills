## Веб-разработка

Принципы создания сайтов и веб-приложений.
Назначение HTML, CSS и JavaScript, разделение структуры, оформления и логики пользовательского интерфейса.
Различия между frontend- и backend-разработкой.
Понятия веб-сервера, клиента, API и доменного имени.
Основные этапы создания сайта: проектирование интерфейса, разработка, тестирование, публикация и сопровождение.
Доступность веб-ресурсов, адаптивная вёрстка и обеспечение удобства использования на разных устройствах.

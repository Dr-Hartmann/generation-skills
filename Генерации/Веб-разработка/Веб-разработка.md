# Веб-разработка

**Основы веб-разработки и создания современных сайтов и веб-приложений.** Понятие веб-разработки, её назначение, основные направления и области применения. Принципы функционирования Всемирной паутины (World Wide Web), архитектура клиент-серверного взаимодействия, особенности работы браузеров и веб-серверов.

**Основные технологии веб-разработки:**

- **HTML (HyperText Markup Language)** — язык гипертекстовой разметки, назначение, структура HTML-документа, основные элементы и семантическая разметка содержимого.
- **CSS (Cascading Style Sheets)** — язык описания внешнего вида веб-страниц, селекторы, свойства, каскадность, наследование, блочная модель, позиционирование, Flexbox и CSS Grid.
- **JavaScript** — язык программирования для реализации интерактивности, обработки пользовательских событий, управления элементами страницы и динамического изменения содержимого.
- **DOM (Document Object Model)** — объектная модель документа, принципы взаимодействия JavaScript с HTML-элементами.
- **JSON (JavaScript Object Notation)** — формат представления и обмена структурированными данными.

**Структура и архитектура веб-приложений.** Разделение представления, бизнес-логики и обработки данных. Различия между frontend- и backend-разработкой, их назначение и взаимодействие. Понятия веб-клиента, веб-сервера, базы данных, доменного имени, URL-адреса, IP-адреса, DNS и хостинга. Принципы работы протоколов HTTP и HTTPS, методы HTTP-запросов и коды состояния ответов сервера.

**Взаимодействие компонентов веб-приложений.** Понятие API (Application Programming Interface), назначение REST API, принципы обмена данными между клиентской и серверной частями. Отправка и обработка HTTP-запросов, получение данных с сервера, использование сторонних веб-сервисов. Основы асинхронного программирования и взаимодействия с сервером без полной перезагрузки страницы.

**Проектирование пользовательских интерфейсов (UI/UX).** Принципы построения навигации, организации содержимого, визуальной иерархии и взаимодействия с пользователем. Понятия пользовательского интерфейса (UI) и пользовательского опыта (UX). Разработка прототипов и макетов, использование дизайн-систем, единообразие элементов интерфейса, формы ввода и обработка пользовательских действий.

**Адаптивная и отзывчивая веб-разработка.** Принципы Responsive Web Design, применение Media Queries, относительных единиц измерения, гибких сеток и адаптивных изображений. Особенности отображения сайтов на компьютерах, планшетах и смартфонах. Подход Mobile First.

**Доступность и удобство использования веб-ресурсов.** Основы Web Accessibility (a11y), семантическая разметка, альтернативные описания изображений, доступная навигация с клавиатуры, контрастность и читаемость содержимого. Знакомство с рекомендациями WCAG. Основные принципы юзабилити и проектирования инклюзивных интерфейсов.

**Основные этапы создания веб-сайта или веб-приложения:**

- Анализ требований, определение целей и целевой аудитории.
- Проектирование структуры сайта, пользовательских сценариев и навигации.
- Разработка прототипов и визуального дизайна.
- Создание клиентской части (Frontend).
- Разработка серверной логики (Backend) и организация хранения данных.
- Интеграция компонентов посредством API.
- Тестирование функциональности, совместимости, производительности и доступности.
- Размещение проекта на хостинге, настройка доменного имени и публикация.
- Мониторинг, техническая поддержка, обновление и дальнейшее развитие.

**Инструменты и среды веб-разработки.** Назначение текстовых редакторов и интегрированных сред разработки (IDE), инструменты разработчика в браузере (DevTools), системы контроля версий Git, платформы совместной разработки, инструменты сборки и управления зависимостями. Основы использования библиотек и фреймворков для frontend- и backend-разработки.

**Безопасность веб-приложений.** Основы защиты веб-ресурсов и пользовательских данных. Понятия аутентификации и авторизации, управление пользовательскими сессиями, безопасное хранение паролей, валидация и проверка пользовательского ввода. Общие принципы защиты от распространённых веб-уязвимостей, включая межсайтовый скриптинг (XSS), SQL-инъекции и подделку межсайтовых запросов (CSRF). Использование HTTPS и соблюдение принципов безопасной разработки.

**Оптимизация и качество веб-ресурсов.** Оптимизация загрузки страниц, изображений, скриптов и таблиц стилей. Кэширование, сжатие ресурсов, минимизация сетевых запросов, основы поисковой оптимизации (SEO), производительность и Core Web Vitals. Кроссбраузерное тестирование и обеспечение стабильной работы веб-приложений.

**Практическое применение веб-разработки.** Создание статических и динамических сайтов, лендингов, информационных порталов, интернет-магазинов, личных кабинетов, интерактивных сервисов и веб-приложений. Разработка простых проектов с использованием HTML, CSS и JavaScript, получение данных из внешних API, публикация готовых работ в интернете.

# App Generator

Детерминированный генератор автономных HTML-миниприложений. Он фиксирует общий документ, метатеги, интерфейс, CSS, адаптивную компоновку, модальное окно, управление, клавиатуру и цикл анимации.

## Требования

- Python 3.10 или новее.
- Без сторонних Python-пакетов.
- Браузер с Canvas 2D, requestAnimationFrame и ResizeObserver.

## Входные файлы

Агент создаёт только два файла:

- scene.json — заголовок, описание и массив шагов с субтитрами;
- scene.js — объект window.AppScene с функцией draw(ctx, frame).

Пример входных файлов находится в examples/.

В scene.js запрещены ES-модули и закрывающий тег </script>, поскольку содержимое встраивается в общий документ. Не создавай собственные html, head, body, meta, style, script, общие контролы или обработчики клавиатуры.

## Генерация

Из корня репозитория:

~~~bash
python app-generator/scripts/generate_app.py \
  --config app-generator/examples/scene.json \
  --scene app-generator/examples/scene.js \
  --output dist/example.html
~~~

Повторная запись существующего файла требует явного --force.

Проверка готового файла:

~~~bash
python app-generator/scripts/validate_app.py dist/example.html
~~~

Результат — один HTML-файл со встроенными CSS и JavaScript. Его можно открыть напрямую в браузере; сервер, сборщик и локальные файлы не требуются.

## Контракт сцены

~~~js
window.AppScene = {
  draw(ctx, frame) {
    // Отрисовать текущий логический шаг.
  }
};
~~~

frame содержит:

- stepIndex — индекс шага, начиная с нуля;
- step — объект метаданных текущего шага;
- width, height — размеры Canvas в CSS-пикселях;
- elapsedMs, deltaMs — время воспроизведения;
- transitionProgress — прогресс перехода от 0 до 1;
- speed, videoMode — текущие настройки;
- palette — канонические цвета из спецификации.

Функция рисования должна быть синхронной и не должна управлять общим таймером, шагами, субтитрами, размерами Canvas или DOM-контролами. Масштабируй графику по width и height, сохраняя пропорции композиции. Не создавай собственный цикл requestAnimationFrame.

Опционально доступны:

- init(api) — вызывается после инициализации DOM и Canvas;
- resize(viewport) — вызывается при изменении размера визуализации;
- reset() — вызывается при общем сбросе.

api в init предоставляет setMode, setPlaying, setSpeed, setVideoMode, nextStep и reset.

## Что контролирует генератор

Единственный нормативный источник параметров — config/app-spec.json. CSS-шаблон, документ и runtime используют эту спецификацию. Генератор автоматически формирует полный viewport meta tag с name="viewport", метатеги, структуру DOM, CSS и стандартный JS runtime.

Проверяются число шагов, длина субтитров, API сцены, уникальность ID, наличие обязательных элементов, встроенность CSS/JS и корректность viewport meta tag.

Не редактируй результат генерации вручную: изменяй входные данные или шаблоны и генерируй файл повторно.

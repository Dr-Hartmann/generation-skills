# short-video-ui-kit

Agent Skill с генератором CSS/HTML/JS-компонентов, извлечённых из `railway-crossing-safety.html`.

## Быстрый запуск

```bash
python scripts/generate_components.py --components all --output ./generated-ui
```

Зависимости: Python 3.10+; сторонние пакеты не нужны.

Подробные правила активации и интеграции — в `SKILL.md`.

# Карта извлечения из исходного HTML

Источник: `railway-crossing-safety.html`.

| Компонент | Исходное место | Что перенесено |
|---|---|---|
| Цветовая палитра UI | CSS: `body`, `.play`, `#panel`, `#modalWrap`, `#modal`, `.seg`, `.sw`, `.keys` | Фон `#0F0F13`, поверхности `#1A1A20`, зелёный акцент `#2EAC65`, тёмный акцент `#1E7A47`, нейтральные и опасные состояния, прозрачности |
| Фон страницы и ambient-слои | CSS `body`, `#ambient`, `.b1`–`.b3`, `@keyframes drift`; HTML `#ambient` | Базовый цвет страницы `#0F0F13`, системная типографика и поведение прокрутки; три размытых слоя, их расположение и цвета, длительность анимаций, включение классом `body.v916` |
| Модальное окно | CSS `#modalWrap`, `#modal`, `.mhead`, `.mstep`, `.seg`, `.mrow`, `.sw`, `.keys`; HTML `#modalWrap` | Затемнение и blur подложки, стеклянная панель, геометрия, состояния кнопок, переключатель, слайдер, подсказки клавиш |
| Управление модальным окном | JS `openSettings`, `closeSettings`, `bind`, `handleInput` | Открытие кнопкой настроек, закрытие крестиком/кликом вне/Escape, события режимов и настроек |
| Палитра Canvas | Цветовые литералы в `drawSky`, `drawTrack`, `drawTrain`, `drawLight`, `drawGauge`, `drawCards` и других `draw*` | Отдельная группа `illustration_palette` в `config/palette.json`; генератор не переписывает код Canvas автоматически |

## Примечания о преобразованиях

- `palette.json` — единственный источник цветовых значений для генерируемого CSS. `theme.css` создаётся скриптом.
- Шаблонные CSS-файлы используют CSS custom properties, а не повторяют шестнадцатеричные значения.
- Контроллер модального окна выдаёт DOM-события `settings:*`. Он не реализует состояние анимации приложения: его обрабатывает основной код миниприложения.
- В шаблон добавлены семантика `role="dialog"`, `aria-modal`, `aria-hidden`, фокус на диалоге и возврат фокуса при закрытии. Внешний вид основан на исходнике.
- Палитра Canvas вынесена в JSON как справочник. Её применение к Canvas требует отдельного перевода цветовых литералов на ссылки к данным палитры.
